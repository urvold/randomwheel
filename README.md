# RandomWheel

Самостоятельный рандомайзер на React + TypeScript + Vite. Русский интерфейс, тёмная адаптивная тема. Сервер и API не требуются, внешних ресурсов во время работы нет.

## Локальный запуск

Node.js 24+, npm:

```sh
npm ci
npm run dev
```

Проверки: `npm test`, `npm run build`. Просмотр сборки: `npm run preview`.

## Возможности

- Колесо из 2–100 редактируемых вариантов, неподвижная стрелка, вращение 5 секунд, окно результата и история 10 результатов.
- Равные вероятности вариантов, предвыбор через Web Crypto, точная остановка в центре сектора с учётом предыдущих поворотов.
- Генератор целых чисел с включительными границами, отрицательными числами и проверкой безопасных целых чисел JavaScript.
- 64-битная выборка с BigInt и rejection sampling исключает смещение по модулю.
- Звуки Web Audio, отключение звука, localStorage с защитой от повреждённых данных и запрета хранилища.
- Мобильная вёрстка, клавиатурный фокус, нативный модальный диалог, reduced motion (без вращения и мелькания чисел).

На колесе длинные названия сокращаются, полные доступны в полях редактора и результате. Максимальная длина варианта — 200 символов. При одинаковых названиях каждый сектор всё равно имеет равную вероятность.

Настройки и история хранятся только в браузере на текущем домене. Очистка данных браузера удаляет их. Для Web Crypto используйте HTTPS или localhost.

## GitHub Pages

Workflow `.github/workflows/pages.yml` готов к публикации после отправки в ветку `main`. В Settings → Pages выберите Source: GitHub Actions. Нужны разрешения на создание репозитория, отправку файлов и запуск Pages/Actions. Относительный base Vite поддерживает размещение по пути `/randomwheel/`.

Публичный репозиторий и публикация требуют отдельного подтверждения владельца.
